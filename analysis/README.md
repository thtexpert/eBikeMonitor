# BLE Log Analysis Scripts

This directory contains utility scripts to extract, analyze, and plot raw Bluetooth Low Energy (BLE) message traffic collected between the Bosch LED Remote/Flow app and your smartphone.

---

## 1. nRF Connect Hex Message Extractor (`hex_extractor.py`)

This script parses raw log files exported from the **nRF Connect** app (available on Android and iOS) and extracts the hex message payloads along with their timestamps.

### Usage
```bash
python hex_extractor.py <input_log_file> [output_file]
```

*   **`<input_log_file>`**: Path to your exported nRF Connect `.txt` or `.log` file.
*   **`[output_file]`**: (Optional) Destination path for the extracted hex data. If omitted, the script automatically saves the output under a `hex/` subdirectory.

### How it Works
*   It parses Android log formats containing `... (0x) [HEX-DATA] ... received` or iOS patterns containing `... "[HEX-DATA]" value received`.
*   It unifies formatting, maps timestamps into milliseconds from the start of the day, prints live updates to the console, and writes a clean line-by-line hex list to the output file.

---

## 2. Bosch BLE Hex Analyser (`hex_analyser.py`)

This script parses the clean hex message output file created by `hex_extractor.py`, decodes all known Bosch Smart System BLE topics (such as Battery State of Charge, Cadence, Human/Motor Power, Assist Modes, Usage Records, and component software versions), and exports the parsed data for analysis.

### Usage
```bash
python hex_analyser.py <extracted_hex_file.txt>
```

*   **`<extracted_hex_file.txt>`**: The clean, extracted hex output file generated by `hex_extractor.py`.

### Outputs Generated
1.  **Summary Table (Console)**: Prints a complete summary of message frequencies, min/max values, packet counts, and consistency indicators (such as monotonicity).
2.  **Processed CSV File**: Generates `<filename>_processed.csv` in the same directory, converting complex varint lists and usage records into JSON strings for easy analysis in Excel or Python.
3.  **Visualization Plot (PNG)**: If `matplotlib` is installed, it automatically generates a multi-panel plot `<filename>_plot.png` visualizing the curves of key telemetry variables over the duration of the log.
